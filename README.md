<p>
  <em>一個以真實強地動波形資料為基礎的前端互動儀表板。<br>解析中央氣象署開放資料，展示地震事件、測站空間分布、三分量波形與估算 P / S 到時之視覺化能力。</em>

> 本專案為個人技術展示用途。  
> 原始波形資料來自交通部中央氣象署開放資料；本專案所呈現之 P / S 到時為簡易估算結果。

---

## 專案摘要

本專案建立一套輕量級震測事件互動儀表板，主要流程如下：

```text
CWA 強地動波形 .dat 檔案
        ↓
Python 解析腳本
        ↓
標準化 JSON 資料
        ↓
前端儀表板
        ↓
地圖測站選擇 + 波形檢視 + P / S 到時標註
```

使用者可以在地圖上點選測站，右側會載入該測站的真實波形資料，並顯示：

- 波形分量：`U`、`N`、`E`
- 振幅單位：`gal`
- 相對發震時間軸
- 發震時刻標註
- 估算 P 波到時
- 估算 S 波到時
- 波形縮放、平移與播放
- 波形圖匯出為 PNG

## 技術展示重點

### 1. 真實科學資料解析

原始資料為中央氣象署強地動波形 `.dat` 檔，檔案包含標頭資訊與時序資料。

本專案使用 Python 解析以下內容：

- 發震時間
- 震央經緯度
- 震源深度
- 地震規模
- 測站代碼
- 測站名稱
- 測站經緯度
- 儀器類型
- 記錄開始時間
- 記錄長度
- 取樣率
- 振幅單位
- `U`、`N`、`E` 三分量波形資料

解析後轉換為前端容易使用的標準化 JSON。

---

### 2. 資料管線設計

為了避免前端直接解析大量原始波形檔，本專案採用「離線解析、前端載入」的資料管線。

```text
data-raw/*.dat
        ↓
scripts/parse_cwa_dat.py
        ↓
data/processed/events.json
data/processed/stations.json
data/processed/waveforms/*.json
```

此設計的好處：

- 前端不需要處理原始文字檔格式。
- 波形資料可依照測站按需載入。
- 資料結構一致，方便後續擴充。
- 適合展示從原始資料到視覺化應用的完整流程。

---

### 3. 地圖與時序圖互動

本專案整合地圖與波形圖：

- 地圖端使用 Leaflet。
- 波形端使用 Plotly.js。
- 前端使用原生 JavaScript 管理狀態與事件流。

互動流程：

1. 載入事件資料。
2. 載入測站資料。
3. 地圖顯示震央與測站。
4. 使用者點選測站。
5. 前端非同步載入該測站波形。
6. 波形圖顯示對應分量。
7. 標註發震時刻、估算 P 到時、估算 S 到時。

---

### 4. 大型波形資料的按需載入

每個測站的波形長度為 90 秒，取樣率為 100 Hz，並包含 `U`、`N`、`E` 三個分量。

若一次性載入所有測站波形，資料量較大。  
因此本專案將每個測站的波形拆成獨立 JSON 檔案，只有在使用者點選測站時才載入。

```text
data/processed/waveforms/{eventId}_{stationCode}.json
```

並在前端加入波形快取，避免重複請求相同測站資料。

---

### 5. 時間軸正規化

原始波形檔中的時間欄位是相對於測站記錄開始時間。

但為了方便分析地震事件，本專案將時間軸正規化為：

```text
發震時刻 = 0 秒
```

例如：

```text
Origin Time：06:44:41
StartTime：  06:44:30
```

代表記錄開始時間比發震時間早 11 秒。

因此前端波形圖的時間軸會顯示為：

```text
-11 秒 至 79 秒
```

其中：

```text
0 秒 = 發震時刻
```

這樣的時間軸更有利於觀察初動、到時與後續波形變化。

## 資料格式

### `events.json`

事件資料包含地震事件的基本資訊：

```json
[
  {
    "id": "20260914064441_121.55_22.63",
    "name": "2026-09-14 M4.9 地震",
    "originTime": "2026-09-14T06:44:41",
    "epicenter": {
      "lat": 22.63,
      "lon": 121.55
    },
    "depthKm": 10.1,
    "magnitude": 4.9,
    "stationCount": 47
  }
]
```

事件 ID 使用：

```text
發震時間 + 震央經度 + 震央緯度
```

如此可將相同地震事件下的多個測站檔案歸入同一事件。

---

### `stations.json`

測站資料包含空間位置與波形元資料：

```json
[
  {
    "eventId": "20260914064441_121.55_22.63",
    "id": "ALS",
    "name": "Alishan",
    "lat": 23.508,
    "lon": 120.813,
    "instrument": "FBA",
    "sampleRate": 100,
    "unit": "gal",
    "distanceKm": 123.4,
    "pArrivalSec": 21.6,
    "sArrivalSec": 36.4
  }
]
```

---

### `waveforms/{eventId}_{stationCode}.json`

每個測站波形檔案包含時間軸與三分量資料：

```json
{
  "time": [],
  "U": [],
  "N": [],
  "E": []
}
```

其中：

| 欄位 | 說明 |
|---|---|
| `time` | 相對發震時間，單位為秒 |
| `U` | 垂直分量，可視為 `Z` |
| `N` | 南北向分量 |
| `E` | 東西向分量 |

## 波形解析流程

解析腳本會執行以下流程：

1. 掃描 `data-raw/` 資料夾中的所有 `.dat` 檔。
2. 解析每個檔案的標頭。
3. 取出地震事件資訊。
4. 取出測站資訊。
5. 解析資料段中的 `Time`、`U`、`N`、`E`。
6. 計算記錄開始時間與發震時間的秒數差。
7. 將時間軸轉換為相對發震時間。
8. 計算測站與震央距離。
9. 估算 P 波與 S 波到時。
10. 輸出標準化 JSON。

---

## P / S 到時估算

原始 `.dat` 檔未直接包含 P 波或 S 波到時。

因此本專案使用簡易距離估算模型：

```text
P 波到時 ≈ 1 秒 + 測站距震央距離 / 6.0 公里每秒
S 波到時 ≈ 1 秒 + 測站距震央距離 / 3.5 公里每秒
```

此估算僅用於展示資料視覺化與互動流程，不代表官方提供之到時資料。

## 快速開始

### 環境需求

- Python 3
- Node.js / npx

本專案的 Python 解析腳本僅使用標準函式庫，不需額外安裝套件。

---

### 1. 放入原始資料

將中央氣象署強地動波形 `.dat` 檔放入：

```text
data-raw/
```

例如：

```text
data-raw/
  1-ALS.dat
  1-B219.dat
  1-C015.dat
  ...
```

---

### 2. 執行資料解析

進入 `scripts` 資料夾：

```bash
cd scripts
```

執行解析腳本：

```bash
python parse_cwa_dat.py
```

若系統需使用 `python3`：

```bash
python3 parse_cwa_dat.py
```

執行完成後，會產生：

```text
data/processed/events.json
data/processed/stations.json
data/processed/waveforms/
```

---

### 3. 啟動前端

回到專案根目錄：

```bash
cd ..
```

啟動本地伺服器：

```bash
npx serve .
```

開啟終端機顯示的網址即可查看。

## 互動功能說明

### 事件選擇

頁面頂部提供事件選擇器。  
目前資料若僅包含單一事件，選擇器仍保留，以便未來擴充多事件資料。

---

### 測站選擇

地圖上的測站可點擊。  
點選測站後，右側會載入該測站波形，並更新測站資訊。

測站資訊包含：

- 測站代碼
- 測站名稱
- 與震央距離
- 估算 P 到時
- 估算 S 到時
- 取樣率
- 儀器類型

---

### 分量切換

波形圖支援三分量切換：

```text
U / N / E
```

其中：

```text
U：垂直分量
N：南北向分量
E：東西向分量
```

---

### 波形縮放

波形圖支援：

- 拖曳框選縮放。
- 滾輪縮放。
- 平移。
- 雙擊重設。
- 工具列操作。
- 波形圖匯出 PNG。

另提供快速縮放按鈕：

| 按鈕 | 功能 |
|---|---|
| 完整 | 顯示完整波形範圍 |
| 發震附近 | 顯示發震時刻附近時段 |
| P / S 附近 | 自動縮放至估算 P / S 到時附近 |

---

### 波形播放

波形播放功能以前端計時器模擬波形推進：

```text
每 500ms 推進 5 秒波形
```

90 秒波形約可在 9 秒內播放完成。

此功能用於展示波形隨時間展開的視覺效果，並非真實即時資料流。

## 已知限制

1. 本專案不含後端服務。
2. 不串接即時資料流。
3. 不包含真實模型推論。
4. 不包含官方 P / S 到時資料。
5. P / S 到時為簡易距離估算。
6. 目前波形以原始振幅顯示，未加入濾波功能。
7. 若未來測站數量大幅增加，可進一步導入分頁、索引檔或後端 API。
